## Canonical Metrics
- Weekly Base Score
- Weekly Final Score
- Quarterly Execution Score
- Sub-KR Goal Execution
- SMART Quality
- Compliance
- Non-Submission
- Integrity Corrections
- Penalty Rate/Amount
- Stretch Goal counts
- Strategic Coverage
- BU Rankings
- Violation Fund inflow/outflow/balance

## Metric Governance
Every metric needs:
- definition;
- formula;
- authoritative source;
- filters;
- timezone;
- rounding;
- null behavior;
- historical behavior;
- tests.

## Critical Distinction
Goal execution against Sub-KRs is not automatically proof that a strategic KR outcome was achieved.

## Data Quality
Detect orphaned Goals/Tasks, missing mappings, invalid statuses, contradictory scores, missing reports and ledger mismatches.

## AI Analytics
Minimize data sent to external AI. Prefer aggregate/non-identifying data. Treat user-entered content as untrusted.

## Definition of Done
Every published metric is reproducible from authoritative data and reconciles to the database.
