## Visual Character
Minimal, premium, polished, authoritative enterprise UX.
Brand direction: dark red + white.

## Principles
1. Show what needs attention.
2. Explain why an action is unavailable.
3. Make state and deadlines visible.
4. Keep routine execution fast.
5. Make high-consequence actions deliberate.
6. Do not use colour alone for state.
7. Use progressive disclosure.
8. Maintain consistent components and interaction patterns.

## Required UX
Lock states must show:
- current state;
- next deadline;
- countdown;
- permitted actions.

SMART UI must show:
- overall score;
- dimensions;
- warnings;
- suggestions.

Integrity UI must show:
- current status;
- target status;
- reason;
- penalty consequence;
- Apply/Waive.

Finance UI must show:
- request;
- available balance;
- post-approval balance;
- justification;
- approval/rejection consequences.

## Definition of Done
Users understand what is happening, what they can do, what is blocked and why, and the consequence of high-risk actions.
